# Project Images

Place project photographs, diagrams, wiring figures, and screenshots in this folder.

Recommended names use lowercase words separated by hyphens, for example:

```text
system-overview.png
fork-mechanism.jpg
rack-sensor-wiring.png
web-interface.png
```

Reference an image from the root `README.md` with:

```markdown
![ASRS system overview](docs/images/system-overview.png)
```
